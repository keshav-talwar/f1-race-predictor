# F1 Race Winner Predictor

Predicts the winner of the 2026 F1 Japanese Grand Prix (Suzuka) from historical results
(2018–2025), 2026 constructor and driver form, career stats and grid position. Uses
Random Forest, Gradient Boosting and Logistic Regression (scikit-learn).

```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python f1_japan_gp_predictor.py
```
